ظهر تحذير واحد upstream من Starlette حول استخدام httpx مع TestClient. لم يُخفَ التحذير ولا يُعد فشل اختبار.

كشفت إعادة الاختبار من بدء خادم بارد أن تأثير تلاشي الصفحة كان يخفض تباين النص أثناء التنقل. أزيل خفض opacity من حركة الإنتاج مع إبقاء الحركة المكانية، وأعيد فحص الإتاحة دون تعطيل قواعد axe أو إخفاء أخطاء التباين. أضيفت مخرجات GitHub annotations لتشخيص CI، وحُدّثت Actions إلى إصدارات Node 24 المثبتة بدلاً من إصدارات Node 20 المتقادمة.

## ما اختُبر فعلياً

### سياسة النموذج والقواعد

- موضع إنشاء YOLO واحد في `app/core/detector.py`، واسم ملف مقبول واحد: `ppe_unified_best.pt`.
- رفض ملف غائب/فارغ، مسار باسم آخر، تحويل symlink إلى اسم آخر، بصمة خاطئة، فئات خارج القائمة أو أسماء مكررة ملتبسة.
- ثقة افتراضية 0.50؛ تطبيع الفئات الصناعية، ضبط الصناديق داخل الصورة ورفض إحداثيات/ثقة غير منتهية أو غير صالحة.
- كاشف مشترك واحد لكل عملية، بما فيها دورة بدء التطبيق الفعلية مع كاشف اختبار صريح.
- فشل دورة البدء عند غياب الوزن **قبل** أي ترحيل أو إنشاء مستخدمين. لا تنزيل أو محمّل بديل.
- ثبات زمني بمؤقت monotonic وتصنيفات سالبة صريحة، reset عند الانقطاع/الإطار النظيف وتغيير القواعد، ومهلة تكرار.

### خط فيديو بموارد فعلية وكاشف اصطناعي

اختبار `tests/integration/test_video_pipeline.py` ينشئ AVI اصطناعياً مؤقتاً، يرفعه عبر API، يشغّل FileSource/OpenCV ومدير الكاميرات، ثم يثبت:

1. قراءة 12 إطاراً مرة واحدة، بمعدل الفيديو المسجل لا بحلقة إعادة فورية.
2. انتقال العدادات عبر الاشتراك، مع استبعاد القواعد غير المفعلة.
3. حفظ JPEG معلّم وصحيح الفك، وصف مخالفة واحد وسجل نجاحه في قاعدة SQL.
4. الوصول إلى دليل الحدث بصلاحية جلسة، ظهوره في SQL statistics وإمكانية معالجته عبر API.
5. انتهاء المصدر و`is_active=False` وتحرير الالتقاط وتصفير حالة الثبات، دون replay عند إعادة التشغيل.
6. فشل الاستدلال ينهي المصدر بوضوح؛ إيقاف التطبيق يحافظ فقط على نية استعادة المصدر الذي أوقف بالإلغاء.
7. إلغاء قراءة أصلية لا يحرر VideoCapture أثناء عمل OpenCV، وإلغاء فتح مصدر يحرره حتى إن لم يسجل بعد.
8. إخفاق commit ينظف الرفع غير المثبت، وإخفاق refresh بعد commit لا يحذف فيديو مصدر مثبت.

**هذا اختبار خط تطبيق، وليس كشفاً حقيقياً لأفراد أو معدات.** الكاشف الاصطناعي يعيد صناديق معروفة للاختبار فقط.

### API والبيانات والصلاحيات

- Admin/Supervisor/Viewer، قراءة فقط للمشاهد ومنع عمليات الإدارة/الرفع غير المخوّلة، بيانات مؤقتة وإبطال جلسات وتدقيق.
- استعادة Admin عبر CLI، منع تعطيل آخر Admin نشط، رفض الأدوار الخارجة عن النطاق وتكرار اسم مستخدم بعد التطبيع، reset/lockout وحساب البداية عند فراغ الجدول فقط.
- المواقع الصناعية الخمسة، الإنشاء والتعديل والتحقق والحذف المقيد بالكاميرات.
- سياسة RTSP/RTSPS، حصر مسارات الفيديو، حجب بيانات اتصال المصدر في الاستجابات وتوقفه عند تغيير URI.
- صور صحيحة/تالفة/فارغة، JPEG/PNG، حجم وبكسلات، اختيار قواعد فارغ/غير معروف، ملفات فيديو ومدة وحصر مسار وتنظيف فشل.
- رفض أجسام multipart الكبيرة، بما فيها النقل المجزأ، قبل معالجة غير محدودة.
- 250 حدثاً في اختبار واحد يثبت أن SQL aggregates لا تعتمد على حد الصفحة، وفلاتر القائمة والتصدير متطابقة.
- ترحيل بيانات فعلية في SQLite، إيقاف المصادر وإبطال الرموز وتطبيع الأدوار وإزالة الحقول السابقة وسلامة العلاقات.

### الواجهة

تعمل الاختبارات في Chromium حقيقي بأبعاد سطح مكتب 1440×1000 ومحاكاة Pixel 7، مع API test fixtures معزولة عن الإنتاج:

- تسجيل الدخول/رفض بيانات خاطئة وتغيير كلمة المرور الإجبارية.
- ألوان MANTIK الدقيقة، RTL وعدم overflow للصفحة، تحميل الرسوم وعدم أخطاء JavaScript في اللوحة.
- إنشاء وتعديل وحذف كاميرا مؤكَّد، إعداد موقع صناعي، إصدار حساب وعرض كلمة مؤقتة ثم إخفاؤها.
- فلاتر الأحداث والدليل والمعالجة وتنزيل CSV، ونتيجة رفع صورة.
- بدء/إيقاف البث بإطارات/عدادات أرسلها API الاختبار، وحالة توقف صادقة للمشاهد.
- حالة تثبيت فارغ دون نسب التزام مختلقة، وتمييز فشل الخادم عن عدم تسجيل الدخول.
- فحوص axe للدخول واللوحة والكاميرات والأحداث والرفع والمواقع والمستخدمين ونافذة الكاميرا، والإغلاق بـEscape وإعادة التركيز إلى زر الفتح.

الصور الملتقطة أثناء الاختبار تعرض **بيانات اختبار**؛ لا تمثل موقع عميل أو نتيجة نموذج معتمد. لا يوجد mock runtime أو حساب تجريبي داخل حزمة الإنتاج.

## بيئة التنفيذ وقابلية الإعادة

Linux Debian 12، Python 3.11.2، Node.js 22.22.3. من الإصدارات المثبتة: FastAPI 0.162.0، Starlette 1.9.0، SQLAlchemy 2.1.6، Alembic 1.20.1، OpenCV-headless 4.14.0.94، NumPy 2.4.6، Pillow 13.0.0، pytest 9.1.1. واجهة Vite 8.3.3، Vitest 5.0.4، Playwright 1.64.1.

استخدمت الجولة المحلية Chromium 153 المعبأ عبر npm بسبب قيود التنزيل. CI مضبوط على تثبيت Chromium القياسي لـPlaywright. لا توجد torch/torchvision/ultralytics في بيئة الاختبار المعزول، ولا وزن معتمد؛ اختبارات المحمل تضع بدائل صريحة لحزم النموذج. متطلبات الاستدلال الفعلية باقية ضمن `requirements/base.txt` للنشر، والاختبارات السريعة ضمن `requirements/test.txt`.

```bash
python -m pip install -r requirements/test.txt
ruff check app migrations scripts tests
ruff format --check app migrations scripts tests
python -m compileall -q app migrations scripts
pytest -q --cov=app --cov-fail-under=75 \
  --cov-report=xml:test-results/coverage.xml --junitxml=test-results/backend.xml
cd frontend
npm ci
npm run lint
npm run format:check
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

المخرجات الخام المحلية غير مضافة إلى Git: `test-results/backend.log` و`backend.xml` و`coverage.xml` و`browser.log` و`approved-model-preflight.log`؛ تفاصيل المتصفح ولقطاته في `frontend/test-results/`. يوفر workflow مخرجات الاختبارات كـCI artifacts عند تشغيله.

## حدود التحقق وبوابة الاعتماد

**التسليم البرمجي مجرَّب؛ اعتماد تشغيل موقع فعلي لم يتم.** يلزم إكمال التالي خارج البيئة الحالية:

- توفير الملف الأصلي المعتمد مع SHA-256 ومصدر وقائمة فئات موثوقة، ثم فحص تحميله واستدلاله الحقيقي. يتحقق المحمل من Person والخوذة والسترة وأزواجهما السالبة على الأقل؛ تحقق من زوج كل قاعدة إضافية قبل اعتمادها.
- قياس precision/recall والإنذارات الكاذبة لكل قاعدة على بيانات موقع معلّمة؛ لا توجد أي أرقام دقة أو FPS معتمدة في هذا التقرير.
- اختبار RTSP حقيقي وFFMPEG ومهل الانقطاع/العودة والأجهزة وحمل الكاميرات والذاكرة والتخزين؛ الحدود الأصلية تعتمد على بناء OpenCV.
- بناء وتشغيل Compose والتحقق من PostgreSQL وTLS والجدار الناري والشهادات والنسخ والاستعادة. Docker CLI غير متاح هنا، وSQL Server غير مختبر تشغيلياً.
- اختبار تسليم SMTP/Webhook الحقيقي؛ الاختبارات تفحص العقود والأخطاء وحجب الأسرار دون إرسال لمستلمين فعليين.
- النسخ الاحتياطية لصور الأدلة والفيديو وإعدادات التثبيت مستقلة عن نسخة SQL. ترحيل الصفوف لا يحذف ملفات قديمة خارج SQL؛ راجعها وفق سياسة الاحتفاظ.
- مدير الكاميرات داخل عملية واحدة؛ لا تدّعِ دعماً لتعدد Uvicorn workers. تصدير CSV يجمع النتيجة المصفاة في الذاكرة؛ اختبر حدود السجلات الكبيرة قبل التوسع.
