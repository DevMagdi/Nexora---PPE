# تشخيص التشغيل المحلي

راجع [README](../README.md) للتشغيل و[الدليل الصناعي](INDUSTRIAL_GUIDE_AR.md) لقواعد المراقبة.

## ملف الوزن أو حزم الاستدلال

```bash
python -m app.model_check --smoke
```

- غياب `Model/ppe_unified_best.pt`: احصل على الملف الأصلي المعتمد من مالكه. لا يعالج تغيير الاسم أو تنزيل وزن آخر المشكلة.
- ملف فارغ/تالف أو عدم تطابق SHA-256: أعد نقل الملف المعتمد وقارن البصمة بسجل الاعتماد.
- مهمة مختلفة عن object detection أو غياب الحد الأدنى Person/Hardhat/NO-Hardhat/Safety Vest: أوقف النشر وراجع تصدير النموذج. الفئات الإضافية غير الصناعية وهويات التكرار تُصفّى؛ غياب NO-Safety Vest يعطّل إنذار السترة السالب فقط، ولا يفشل البدء أو يخفي السترة الموجبة.
- حزم غير موجودة: فعّل البيئة الصحيحة وثبّت `requirements/dev.txt` للتطوير أو `requirements.txt` للنشر. `requirements/test.txt` مخصص للاختبارات المعزولة ولا يشمل torch/ultralytics.
- نجاح إطار فارغ ليس قياس دقة؛ يلزم فيديو وصور معلّمة من الموقع.

## صفحة الدخول تظهر لكن لا يوجد خادم

Vite يستطيع عرض الواجهة على 5173 دون API؛ هذا لا يعني عمل الاستدلال. رسالة «الخادم غير متاح» تميّز هذا الوضع عن جلسة غير مسجلة. تحقق من سجل API وفحص الوزن، ثم أعد التحقق.

للتطوير المحلي استخدم عنوان Vite في المتصفح واحتفظ بالطلبات نسبية. `VITE_API_PROXY_TARGET` عنوان يستخدمه خادم Vite نفسه؛ في Compose قيمته `http://app:8000`. لا تستخدم عنوان جهاز الخادم المحلي داخل شفرة المتصفح للوصول إلى خدمة أخرى.

## حساب البداية لا يعمل

- `BOOTSTRAP_USERNAME` و`BOOTSTRAP_PASSWORD` يُستخدمان عندما يكون جدول المستخدمين فارغاً فقط.
- القيم العشوائية الافتراضية للتطوير تتغير بين عمليات التشغيل؛ ضبط متغيرات دائمة يمنع الالتباس. لا تعتمد سجل التطوير كقناة لتوزيع كلمات المرور في الموقع.
- حساب قائم أو حساب معطّل لا يُستبدل تلقائياً. استخدم CLI المحلي:

  ```bash
  python -m app.cli list-users
  python -m app.cli reset-password --username site.admin
  python -m app.cli create-user --username recovery.admin --role admin
  ```

- إعادة كلمة المرور تُبطل الجلسات القديمة وتفرض التغيير عند الدخول. الحساب المعطل يحتاج إجراء إدارة صريحاً؛ إنشاء Admin محلي جديد هو مسار الاستعادة عند غياب Admin صالح.
- تغيير `JWT_SECRET` أو ترقية النطاق تُبطل الجلسات. سجّل الدخول من جديد ولا تخزّن الرموز أو كلمات المرور في المتصفح.

## المصدر يفتح دون إطارات

تحقق من المسار واسم/كلمة مرور الكاميرا وVLAN والجدار الناري وإتاحة RTSP/RTSPS ومنع استخدام المصدر بواسطة خدمة أخرى. يجب أن يغطي `ALLOWED_RTSP_PREFIXES` الأصل الحقيقي بالضبط. يرفض API التشغيل إذا لم يصل إطار معالج في المهلة.

انتهاء فيديو مرفوع حالة طبيعية: المصدر يصبح متوقفاً، وليس بثاً حياً متصلاً. شغّله صراحة لإعادة التحليل. `is_active` نية استعادة التشغيل، بينما `is_running` يتطلب إطاراً حديثاً وعاملاً يعمل؛ لا تخلط بينهما.

## Windows وقيود الوحدات الأصلية

```bash
python scripts/check_native_deps.py
python scripts/alembic_cli.py current
```

يدعم `app/native_compat.py` مسار SQLAlchemy النقي عند حظر وحداته المترجمة بسياسة النظام؛ هذا لا يغير سياسة وزن النموذج. لا تعطّل سياسات المؤسسة من أجل حل رسالة DLL؛ راجع مسؤول الجهاز. عند استخدام SQL Server ثبّت `requirements/mssql.txt` وODBC Driver المناسب واختبر الاتصال والترحيل هناك.

## رفع غير ناجح / 413 / 422

JPEG/PNG للصور وMP4/AVI للفيديو فقط. افتراضياً: 100 MB، 24 مليون بكسل، 120 ثانية للفيديو. يجب أن يكون `UPLOADS_DIR` داخل `ALLOWED_VIDEO_DIR`، مع صلاحيات كتابة ومساحة كافية. الحد يطبق أيضاً على جسم multipart المجزأ، مع هامش لترويساته. لا تحاول تجاوز الحد بتغيير الامتداد.

## مصادر MJPEG/HLS وUSB

- ظهور رفض HTTP قبل الفتح يعني غالبًا أن `ALLOWED_HTTP_CAMERA_PREFIXES` فارغة، أو أن المنفذ/المسار أو أحد موارد HLS خارج السياسة. لا توسّعها إلى جميع الوجهات؛ أضف الأصل الحقيقي فقط.
- التحويل302/301 غير مدعوم عمدًا؛ أدخل الرابط النهائي. لا تُقبل صفحة الكاميرا أو لقطة ثابتة كمصدر MJPEG.
- HLS: رابط `.m3u8` عادي بمسار مدمج، لا LL-HLS أو DRM. مع mediamtx اضبط `hlsVariant: mpegts` أو `fmp4`. راجع حدود الموارد وPTS في الدليل الصناعي.
- ثبّت `requirements/runtime.txt` المحدثة لتوفير PyAV/FFmpeg الخاص بفك HLS. لا يحتاج التشغيل إلى executable من `imageio-ffmpeg`؛ تلك الحزمة لاختبارات توليد الفيديو فقط.
- USB يخص جهاز الخادم، ويحتاج APP_ENV=dev وENABLE_USB_SOURCES وفهرسًا مسموحًا. لا تستخدمه في إنتاج ولا تفترض أن فهرس0 موجود.
- ONVIF عنوان تعريف فقط، ليس اكتشافًا تلقائيًا أو اتصال فيديو.
- [تقرير التحديث الحالي](SOURCE_AND_THEME_UPDATE.md) يميّز الاختبارات الاصطناعية وحدود التحقق الميداني.

## موجب وسالب متعارضان أو إنذار غير متوقع

- يجب أن تمر نتيجة الكاشف من `app/core/postprocess.py` قبل المعاينة والعدادات والإنذار. لا تستخدم صناديق YOLO الخام مباشرة في واجهة أخرى.
- Hardhat 0.68 + NO-Hardhat 0.60 في المنطقة نفسها → موجب فقط. لا يفوز السالب على الموجب إلا بفارق 0.15 على الأقل؛ لا تخفضه لإظهار حدث في العرض.
- افحص `/api/v1/meta/system` بعد المصادقة: `confidence` للعرض، `negative_confidence` المضبوطة و`effective_negative_confidence` الفعلية، وقدرات القواعد من خريطة الوزن. حد السالب الافتراضي 0.60 مع الثبات، وليس حد العرض 0.50 وحده.
- «عرض فقط» لا يعني تعطل كشف السترة الموجبة. غياب فئتها السالبة يمنع إنذارها فقط؛ لا تحاول تصنيع اسم فئة أو وزن بديل.
- الصورة المفردة لا تسجل مخالفة. لا تعتبر صندوقًا أحمر فيها أو مرور اختبارات اصطناعية دليلًا على إنذار زمني أو على دقة النموذج بالموقع.
