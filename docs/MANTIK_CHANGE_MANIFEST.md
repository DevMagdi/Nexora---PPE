## ما حُفظ عمدًا

- لا تعديل في ترحيلات DB أو قارئات RTSP/RTSPS/MJPEG/HLS/file/USB أو سياسة المصدر؛ تعديل HTTP الوحيد اسم User-Agent، ومدير الكاميرات يضيف الحسم وبوابة القدرات.
- لا إعادة تسمية لمستودع GitHub أو cookies أو متغيرات التركيب أو صيغة النسخ المشفرة أو مسارات التخزين القائمة؛ هذه أسماء تقنية متوافقة لا هوية الواجهة.
- لا حذف أو تعطيل للاختبارات، ولا خفض لعتبة coverage البالغة 75%، ولا إضافة بيانات تجريبية إلى التطبيق المنتج.
- كل صور المراجعة الست الحالية ببيانات اختبار واجهة فقط. الأصول والتقارير السابقة محفوظة كسجل تاريخي مستقل.
